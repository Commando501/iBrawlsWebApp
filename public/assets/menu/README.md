# Menu game captures

These PNGs are the approved menu study renders, copied without image generation or retouching. Character imagery uses the game's V3 Iron Vanguard asset and pose pipeline (the shipped Iron Vanguard GLBs), and Stadium imagery is captured from actual game rendering.

- `training-iron-vanguard.png`: three actual Iron Vanguard models in action.
- `tournament-iron-vanguard.png`: four red and four blue Iron Vanguards contesting the center ball.
- `online-iron-vanguard.png`: four actual Iron Vanguards waiting to play.
- `stadium-gameplay.png`: captured Championship Stadium gameplay.
- `iron-vanguard-reference.png`: actual front sword pose, used only as a model-loading fallback.

Live model views load the production CharacterPreview and Iron Vanguard assets. Map previews render the selected map data. Theater heatmaps animate the selected recording's actual events. These PNGs are static captures, not live match feeds.
